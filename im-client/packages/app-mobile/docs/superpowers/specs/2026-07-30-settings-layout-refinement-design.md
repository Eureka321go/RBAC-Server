# IM 客户端设置与布局收口设计

## 目标

在不改变现有品牌色、圆角和信息层级的前提下，解决 Android 上卡片阴影脏、通讯录目录未利用剩余空间、个人页设置难以扩展的问题。

## 已确认方案

采用设置列表加二级页面的方案：

- “我的”页保留身份卡片，下方改为统一的偏好设置列表。
- “外观”行显示当前模式，点击进入外观二级页。
- 外观二级页以三行单选项展示“跟随系统、浅色、深色”，当前项显示勾选；切换后立即生效并保存现有主题偏好。
- “语言”行显示“简体中文”，作为暂不执行真实国际化的占位入口，不改变 App 文案。
- 退出登录继续作为独立危险操作，避免混入普通设置。

## 全局视觉规则

- 删除共享卡片、底部 Tab 和聊天输入区域中的 iOS 阴影与 Android elevation。
- 保留细边框、背景层级和圆角作为容器边界，亮色与暗色模式使用现有主题色。
- 不新增渐变、装饰资产或新的视觉语言。

## 通讯录布局

- 页面顶部标题、快捷入口和“组织成员”标题保持现有结构。
- 页面主体改为纵向弹性布局，通讯录卡片占满底部 Tab 之上的全部剩余空间。
- 目录内部继续由现有列表独立滚动，部门层级、联系人选择和创建会话逻辑不变。
- 加载和错误状态也占用同一剩余区域，避免卡片高度跳变。

## 导航与组件边界

- 在根 Stack 增加外观设置路由和独立屏幕，沿用现有紧凑型返回栏。
- “我的”页只负责展示当前设置摘要和触发导航。
- 现有主题状态继续由 `ThemeProvider` 管理，不引入新的状态库。
- 语言占位入口不创建翻译资源、语言状态或持久化逻辑。

## 交互与无障碍

- 设置行使用完整行点击区域、清晰的图标、当前值和箭头。
- 外观选项使用 radio 语义和 selected 状态，勾选图标与主题主色一致。
- 语言占位行明确标注“简体中文”，但本轮不触发语言切换。
- 阴影移除后仍通过边框和色差维持可辨识的层级。

## 测试与验收

- 单元测试覆盖共享容器无阴影、个人页设置入口、外观二级页选择和根导航注册。
- 布局测试验证通讯录目录容器使用 `flex: 1`，不再依赖固定高度。
- 运行 Jest、TypeScript、ESLint 和 Android Debug 构建。
- 在 Android 模拟器分别检查亮色与暗色下的通讯录、个人页和外观二级页。

## 非目标

- 本轮不实现简体中文以外的翻译。
- 本轮不修改通讯录数据结构、联系人权限或聊天创建流程。
- 本轮不调整消息气泡、头像、品牌色或字体体系。
