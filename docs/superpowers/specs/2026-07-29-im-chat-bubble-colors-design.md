# IM 聊天气泡颜色调整设计

## 目标

统一聊天消息的视觉颜色：己方与对端消息气泡均使用白色，普通正文使用黑色，结构化 `@成员` 与 `@所有人` 片段使用浅蓝色文字。

## 实现范围

- `ChatScreen` 中己方和对端气泡统一使用现有白色表面色；对端继续保留现有细边框，己方不新增边框。
- `MentionText` 中己方和对端普通正文统一使用现有深色正文色。
- 所有合法提及片段统一使用浅蓝色文字，不再添加提及背景色。
- 不调整气泡圆角、间距、发送状态、头像、长按操作、提及解析和安全降级逻辑。

## 验证方式

按项目约定不新增或运行自动化测试。实现后执行 SDK Core、移动端 TypeScript 检查和 `git diff --check`，由用户手动检查己方、对端、普通正文、成员提及与 `@所有人` 五类显示。
