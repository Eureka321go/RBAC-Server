# RBAC 系统 —— 主题切换设计文档

> 记录时间：2026-07-08
> 当前基础：前端 Vue 3.5 + TS + Vite + Pinia + Element Plus 2.14 + Tailwind 4（CSS-first，无 tailwind.config）
> 本阶段目标：为后台引入亮色/暗色模式与主题色切换，Element Plus 与 Tailwind 统一联动，偏好持久化

---

## 一、设计目标

- **明暗模式**：`light` / `dark` / `auto`（跟随系统 `prefers-color-scheme`）。
- **主题色（primary）**：可切换品牌主色，自动派生 Element Plus 各级色阶。
- **统一联动**：Element Plus、Tailwind、自定义组件共用同一套 CSS 变量与切换开关。
- **持久化 + 防闪烁**：偏好存 `localStorage`，首屏在挂载前应用，避免"亮→暗"闪烁（FOUC）。
- **可扩展**：主题偏好纳入统一 `settings` store，未来可承载布局、紧凑度等更多外观项。

---

## 二、技术选型与原理

| 目标 | 方案 |
|------|------|
| 暗色开关载体 | `<html>` 上切换 `class="dark"`（Element Plus 官方约定） |
| Element Plus 暗色 | 引入 `element-plus/theme-chalk/dark/css-vars.css` |
| Tailwind 4 暗色 | CSS-first：`@custom-variant dark (&:where(.dark, .dark *));`，使 `dark:` 变体基于 `.dark` |
| 主题色派生 | 覆盖 `--el-color-primary` 及 `--el-color-primary-light-{3,5,7,8,9}` / `-dark-2` |
| 跟随系统 | `window.matchMedia('(prefers-color-scheme: dark)')` 监听 |
| 状态管理 | Pinia `useSettingsStore` |

**核心机制**：一切外观由挂在 `<html>` 上的 `.dark` class 和一组 CSS 变量驱动。Element Plus 和 Tailwind 都以此为准，切换时只需增删 class 与改写 CSS 变量，无需重载样式表。

---

## 三、前端实现

### 1. 样式入口

`main.ts` 追加 Element Plus 暗色变量表（在主样式之前）：

```ts
import 'element-plus/dist/index.css'
import 'element-plus/theme-chalk/dark/css-vars.css'  // 暗色变量
import './assets/main.css'
```

`assets/main.css`（Tailwind 4 CSS-first）声明暗色变体与自定义变量：

```css
@import "tailwindcss";

/* 让 Tailwind 的 dark: 变体基于 <html class="dark"> */
@custom-variant dark (&:where(.dark, .dark *));

/* 应用级语义变量，明暗各一套（供自定义组件使用） */
:root {
  --app-bg: #f5f7fa;
  --app-surface: #ffffff;
  --app-text: #303133;
}
.dark {
  --app-bg: #141414;
  --app-surface: #1d1e1f;
  --app-text: #e5eaf3;
}
```

### 2. Pinia settings store

```ts
// stores/settings.ts
export type ThemeMode = 'light' | 'dark' | 'auto'
const STORAGE_KEY = 'app-settings'

export const useSettingsStore = defineStore('settings', () => {
  const mode = ref<ThemeMode>('auto')
  const primary = ref<string>('#409eff')   // Element Plus 默认主色

  // 实际生效的明暗（auto 时解析系统偏好）
  const isDark = ref(false)

  function resolveDark(m: ThemeMode) {
    if (m === 'auto') return matchMedia('(prefers-color-scheme: dark)').matches
    return m === 'dark'
  }

  function applyTheme() {
    isDark.value = resolveDark(mode.value)
    document.documentElement.classList.toggle('dark', isDark.value)
    applyPrimary(primary.value)
    persist()
  }

  function setMode(m: ThemeMode) { mode.value = m; applyTheme() }
  function setPrimary(color: string) { primary.value = color; applyTheme() }

  function persist() {
    localStorage.setItem(STORAGE_KEY, JSON.stringify({ mode: mode.value, primary: primary.value }))
  }
  function hydrate() {
    const raw = localStorage.getItem(STORAGE_KEY)
    if (raw) { const s = JSON.parse(raw); mode.value = s.mode ?? 'auto'; primary.value = s.primary ?? primary.value }
  }

  return { mode, primary, isDark, applyTheme, setMode, setPrimary, hydrate }
})
```

### 3. 主题色派生

Element Plus 主色需要 primary 及其亮/暗色阶。用白/黑混合生成：

```ts
// utils/theme.ts
function mix(color: string, target: string, weight: number): string { /* 十六进制线性混合 */ }

export function applyPrimary(primary: string) {
  const el = document.documentElement.style
  el.setProperty('--el-color-primary', primary)
  // light-3/5/7/8/9：与白色混合；暗色模式与黑色混合
  const dark = document.documentElement.classList.contains('dark')
  const mixTarget = dark ? '#141414' : '#ffffff'
  ;[3, 5, 7, 8, 9].forEach((lvl) => {
    el.setProperty(`--el-color-primary-light-${lvl}`, mix(primary, mixTarget, lvl / 10))
  })
  el.setProperty('--el-color-primary-dark-2', mix(primary, dark ? '#ffffff' : '#000000', 0.2))
}
```

### 4. 防首屏闪烁

在 `index.html` 的 `<head>` 内联一段**同步脚本**，在应用挂载前先给 `<html>` 打上 `.dark`：

```html
<script>
  (function () {
    try {
      var s = JSON.parse(localStorage.getItem('app-settings') || '{}')
      var mode = s.mode || 'auto'
      var dark = mode === 'dark' ||
        (mode === 'auto' && matchMedia('(prefers-color-scheme: dark)').matches)
      if (dark) document.documentElement.classList.add('dark')
    } catch (e) {}
  })()
</script>
```

`main.ts` 挂载前 `useSettingsStore().hydrate()` + `applyTheme()`，与内联脚本结果一致，避免抖动。

### 5. 跟随系统监听

`auto` 模式下监听系统变化实时切换：

```ts
matchMedia('(prefers-color-scheme: dark)').addEventListener('change', () => {
  if (settings.mode === 'auto') settings.applyTheme()
})
```

### 6. 切换 UI

- **顶栏开关**：亮/暗快捷切换按钮（`el-switch` 或图标按钮，Sunny/Moon 图标）。
- **设置抽屉（可选）**：`el-drawer` 内含模式三选一（light/dark/auto）+ 主题色 `el-color-picker` + 预设色板。

自定义组件样式统一用语义变量（`bg-[var(--app-surface)]`、`text-[var(--app-text)]`）或 Tailwind `dark:` 变体，禁止写死颜色。

## 四、与后端联动（可选）

主题偏好可仅存本地（推荐，够用）。若需跨设备同步：

- `sys_user` 扩展 `theme_mode`、`theme_primary` 或统一 `preferences` JSON 列。
- 登录 `GET /api/auth/me` 返回偏好，前端 hydrate 时优先采用；`PUT /api/user/profile/preferences` 保存。
- API 层字段 camelCase：`themeMode` / `themePrimary`。

## 五、实施顺序

1. **样式基建**：`main.css` 加 `@custom-variant dark` 与语义变量；`main.ts` 引入 Element Plus 暗色 css-vars。
2. **settings store**：`mode` / `primary` / `hydrate` / `applyTheme`。
3. **防闪烁脚本**：`index.html` 内联初始化。
4. **明暗切换 UI**：顶栏开关，验证 Element Plus 组件与页面整体切换正常。
5. **跟随系统**：`auto` 模式 + `matchMedia` 监听。
6. **主题色派生**：`utils/theme.ts` 色阶生成 + 设置抽屉的 color-picker。
7. **自定义组件适配**：排查写死颜色，替换为语义变量/`dark:` 变体。
8. **（可选）后端偏好同步**。

---

## 六、注意事项

- **单一事实来源**：明暗只由 `<html>.dark` 决定，Element Plus 与 Tailwind 都据此判断，禁止各自维护第二套开关。
- **防闪烁必做**：内联脚本与 store 初始化逻辑必须一致，否则首屏会闪。
- **对比度与可访问性**：暗色下文字/背景对比度需满足 WCAG AA；主题色选择器可提示低对比色。
- **图表联动**：Dashboard 图表（dataviz）需读取当前主题切换配色，明暗切换时重绘。
- **打印/导出**：如有打印场景，强制走亮色，避免暗色浪费墨。
- **与 i18n 解耦**：主题与语言是相互独立的两套偏好，共用 `settings` 概念但互不影响。
