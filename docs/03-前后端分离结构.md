## 一、目标结构

采用 **monorepo（单仓多目录）** 布局，前后端同仓、目录隔离：

```
RBAC-Server/
├── .gitignore
├── docs/                      # 项目文档（前后端共享）
├── deploy/                    # 中间件编排（前后端共享）
│   ├── docker-compose.yml
│   ├── .env
│   └── config/...
├── backend/                   # ← 后端：Spring Boot 3 + JDK 21
│   ├── pom.xml
│   └── src/main/
│       ├── java/com/rbac/...
│       └── resources/application.yml
└── frontend/                  # ← 前端：Vue3 + Vite + TS
    ├── package.json
    ├── vite.config.ts
    ├── index.html
    └── src/
        ├── main.ts
        ├── App.vue
        ├── router/index.ts
        ├── api/request.ts     # axios 实例，baseURL=/api
        ├── views/HomeView.vue # 占位页 + 后端连通检测
        └── assets/main.css
```

**变更点：** 原来根目录下的 `pom.xml`、`src/` 已移入 `backend/`；`target/`（编译产物）已删除，在 `backend/` 内重新生成。

## 三、前后端联调约定

- 后端 `context-path = /api`，端口 `8080`。
- 前端 axios `baseURL = /api`。
- 开发环境由 **Vite 代理**把 `/api/**` 转发到后端 `http://localhost:8080`（见 `frontend/vite.config.ts` 的 `server.proxy`）。
- 因此前端发 `/api/ping` → 代理到 `http://localhost:8080/api/ping` → 命中后端探活接口。

## 四、启动与验证

### 1. 中间件（一次）
```bash
cd deploy && docker compose up -d
```

### 2. 后端
```bash
cd backend
export JAVA_HOME="$(brew --prefix openjdk@21)/libexec/openjdk.jdk/Contents/Home"
mvn -DskipTests clean package
"$JAVA_HOME/bin/java" -jar target/rbac-server-0.0.1-SNAPSHOT.jar
# 起在 http://localhost:8080/api
```

### 3. 前端
```bash
cd frontend
npm install          # 首次
npm run dev          # 起在 http://localhost:5173
```

### 4. 验证
- 浏览器打开 http://localhost:5173
- 点击页面上的「检测后端连通性」按钮
- 若返回 `{ mysql: "UP", redis: "UP" }`，说明**前端 → 后端 → MySQL/Redis** 全链路打通。

也可单独验证：
- 后端：`curl http://localhost:8080/api/ping`
- 前端构建：`cd frontend && npm run build`（含 TS 类型检查）
