# RBAC 系统 —— 后端骨架搭建记录

> 记录时间：2026-07-08

## 一、技术选型

| 组件 | 版本 | 说明 |
|------|------|------|
| Spring Boot | 3.4.1 | 基础框架，要求 JDK 17+，本项目用 JDK 21 |
| JDK | 21 (LTS) | `<java.version>21</java.version>` |
| Spring Web | 随 Boot | REST 接口 |
| Spring Security | 随 Boot | 认证 / 鉴权（骨架阶段先全放行） |
| Spring Data Redis | 随 Boot | Redis 访问，Lettuce 连接池 |
| MyBatis-Plus | 3.5.9 | `mybatis-plus-spring-boot3-starter`（Boot 3 专用） |
| MySQL 驱动 | com.mysql:mysql-connector-j | 随 Boot 管理版本 |
| Lombok | 随 Boot | 简化样板代码 |
| 参数校验 | spring-boot-starter-validation | 后续 DTO 校验 |

> ⚠️ 注意：MyBatis-Plus 在 Spring Boot 3 下必须用 **`mybatis-plus-spring-boot3-starter`**，
> 旧的 `mybatis-plus-boot-starter` 不兼容 Boot 3。

## 二、项目结构

```
RBAC-Server/
├── pom.xml                                  # Maven 依赖与构建
└── src/main/
    ├── java/com/rbac/
    │   ├── RbacServerApplication.java        # 启动类（@MapperScan("com.rbac.**.mapper")）
    │   ├── common/

    │   ├── config/

    │   └── controller/
    │       └── PingController.java            # 探活接口，验证 MySQL/Redis 连通
    └── resources/
        └── application.yml                    # 数据源 / Redis / MyBatis-Plus 配置
```

## 三、关键配置说明

### 1. 服务与上下文
- 端口 `8080`，`context-path: /api`，所以接口实际路径都带 `/api` 前缀。

### 2. 数据源（对接 deploy 的 MySQL）
- URL：`jdbc:mysql://localhost:3306/rbac`，账号 `rbac` / `rbac_123`。
- 连接池 HikariCP，池名 `RbacHikariPool`。

### 3. Redis（对接 deploy 的 Redis）
- `localhost:6379`，密码 `rbac_redis_123`，Lettuce 连接池。

### 4. MyBatis-Plus
- 开启驼峰映射；预置**逻辑删除**字段约定 `deleted`（0 未删 / 1 已删），
  后续实体加 `@TableLogic` 即生效。
- `mapper-locations: classpath*:mapper/**/*.xml`。

### 5. Spring Security（骨架阶段）
- 关闭 CSRF、无状态会话、**暂时放行所有请求**，便于验证打通。
- 已注入 `BCryptPasswordEncoder`，供后续注册 / 认证使用。
- 后续接入 JWT 与鉴权规则时在 `SecurityConfig` 扩展。

## 四、构建与运行

```bash
# 确保用 JDK 21（否则 java -jar 会报 UnsupportedClassVersionError）
export JAVA_HOME="$(brew --prefix openjdk@21)/libexec/openjdk.jdk/Contents/Home"

# 编译打包
mvn -DskipTests clean package

# 运行（用 21 的 java；PATH 默认可能仍是 17，建议用绝对路径或先 source ~/.zshrc）
"$JAVA_HOME/bin/java" -jar target/rbac-server-0.0.1-SNAPSHOT.jar
```

> **踩坑记录**：编译时 Maven 用 `JAVA_HOME`（21）生成 class 版本 65.0，
> 但直接 `java -jar` 若走 PATH 里的旧 `java`（17，最高只认 61.0）会报
> `UnsupportedClassVersionError`。解决：运行时也用 JDK 21。
